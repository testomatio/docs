A tutorial is a short, step-by-step guide that walks you through one real task in Testomat.io from beginning to end. You follow along, click as you go, and by the end you have actually done the thing, not just read about it. No prior knowledge needed. If you are new, start with the first one and work your way down.

- **[Manual Testing - Classic](./Manual-Testing-Classic.md)** - create your first project, add a few test cases, run them by hand, and see the results. The best place to start.
- **[Manual Testing - BDD](./Manual-Testing-BDD.md)** - the same, for teams that write tests as Given / When / Then scenarios.
- **[Working With Plans](./Working-with-Plans.md)** - build a plan once, then launch it as a run again and again.
- **[Working With Jira](./Working-with-Jira.md)** - connect Testomat.io to Jira to link tests to issues and report bugs without leaving your run.
- **[Using AI in Testing](./Using-AI-in-Testing.md)** - let AI create test data, summarize a suite, and answer questions about your tests.
- **[MCP - Connect AI Assistant](./mcp-connection.md)** - connect Claude, Cursor, or OpenCode to your project through the MCP Server.
- **[Interacting via API](./Interacting-via-API.md)** - pull your tests and create runs from code.
- **[Set Up Read-Only Access](./Set-Up-Read-Only-Access.md)** - give a client, manager, or auditor a safe way to look at your tests without changing anything.
- **[Migration from TestRail](./Migration-from-TestRail.md)** - already have tests in TestRail? Bring them into Testomat.io.
- **[Playwright](./playwright.md)** - report Playwright results to Testomat.io.
- **[Java Integration](./java.md)** - report JUnit, TestNG, or Cucumber JVM results to Testomat.io.
- **[WebdriverIO](./webdriver.md)** - report WebdriverIO results to Testomat.io.
