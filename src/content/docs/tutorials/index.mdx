A tutorial is a short, step-by-step guide that walks you through one real task in Testomat.io from beginning to end. You follow along, click as you go, and by the end you have actually done the thing, not just read about it. No prior knowledge needed. If you are new, start with the first one and work your way down.

- **Manual Testing - Classic** - create your first project, add test cases, run them by hand, and see the results.
- **Manual Testing - BDD** - for teams that write tests as Given / When / Then scenarios.
- **Working With Plans** - build a plan once, then launch it as a run again and again.
- **Working With Jira** - connect Testomat.io to Jira to link tests to issues. Report bugs without leaving your run.
- **Using AI in Testing** - let AI create test data, summarize a suite, and answer questions about tests.
- **MCP - Connect AI Assistant** - connect Claude, Cursor, or OpenCode to the project through the MCP Server.
- **Interacting via API** - pull tests and create runs from code.
- **Set Up Read-Only Access** - give a client a safe way to look at your tests without changing anything.
- **Migration from TestRail** - already have tests in TestRail? Bring them into Testomat.io.
- **Playwright** - report Playwright results to Testomat.io.
- **Java Integration** - report JUnit, TestNG, or Cucumber JVM results to Testomat.io.
- **WebdriverIO** - report WebdriverIO results to Testomat.io.
